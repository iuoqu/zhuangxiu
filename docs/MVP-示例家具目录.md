# MVP 示例家具目录

`sample-furniture.js` 录入了 9 件虚构办公家具：单人桌、双人工作台、屏风工位、六人会议桌、电话亭、经理桌、文件柜、前台、沙发。

每件包含 `DEMO-` 编号、名称、长宽高（毫米）、演示价格和由若干盒体组成的简化几何。`studio.js` 使用同一目录进行摆放、方案生成、清单汇总和 3D 预览；新摆放的家具会保存编号和目录版本。

这些不是厂家 SKU，也不是 GLB、RFA 或精确 BIM 模型。尺寸、外观及价格仅用于验证 MVP 流程，不可用于采购、报价、施工、消防或无障碍合规判断。后续替换真实产品时，应加入厂家、系列、型号、版本、规格约束、模型文件、材质和正式价格来源，并迁移既有项目中的演示编号。
